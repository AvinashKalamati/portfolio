# Portfolio — Avinash Kalamati

Personal portfolio site for Avinash Kalamati, Software Development Engineer (Backend & AI Infrastructure).

Race-weekend edition: McLaren black & papaya orange, carbon-fiber texture, F1 start-lights,
a telemetry stat bar, experience as a Race Record, skills as a Spec Sheet, open source as Podium finishes.

## Run it

The whole site is one self-contained file — `index.html` (styles, scripts and images inlined).
Open it in any browser, or serve the folder with any static server, e.g.:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
